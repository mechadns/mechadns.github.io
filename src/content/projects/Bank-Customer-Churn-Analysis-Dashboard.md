# Power BI - Customer Churn Analysis Dashboard Project

This Power BI project provides interactive dashboards and advanced visual analytics for customer churn data. It helps businesses identify key trends, understand customer behavior, and make data-driven decisions.

## 📁 File Structure
- `.pbix` file: The main Power BI report containing data models, transformations, and visuals.
- `.csv` file: The dataset used for analysis.

## 🚀 Features
- 📈 Interactive dashboard report

## 📦 Requirements
To run this project, you need:
- [Power BI Desktop](https://powerbi.microsoft.com/desktop/)

## 🛠️ How to Use
1. Download or clone the repository.
2. Open the `.pbix` file using Power BI Desktop.
3. If prompted, update data source settings to match your local or cloud data path.
4. Explore and interact with the dashboards.

For more details, visit the [GitHub Repository](https://github.com/mechadns/PowerBI-bankcustomerchurnanalysis).
